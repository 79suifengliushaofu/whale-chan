鲸鱼娘 · 便携版（U 盘 / 移动硬盘）
====================================

插上 U 盘，双击 whalechan.cmd 就能跟她说话。不用在这台电脑上装任何东西。


一、这个目录里是什么
--------------------

  whalechan.cmd        ← 双击这个（整个便携版的入口）
  node\                Node.js 运行时（98 MB）
  app\                 DeepSeek Harness（dsh）本体（462 MB）
  whale-chan\          鲸鱼娘本体（5 MB）
  data\                你的东西：API Key、人设、记忆、好感度、会话（都在这）
  使用说明.txt          本文件

  合计约 570 MB。

  ⚠️ 拷到 U 盘时**要整个目录一起拷**，别只拷 whalechan.cmd。
     启动器里所有路径都是用「自己的位置」算出来的，拆开就找不到。


二、第一次用之前
----------------

两种给 Key 的方式，选一种：

  【推荐】在 data\ 里新建一个 key.txt，里面只写一行：

      sk-你的DeepSeek密钥

  没有换行、没有引号、没有多余空格。下次双击 whalechan.cmd 就会自动读到。

  【或者】插上 U 盘后，在那台电脑上设一个环境变量 DEEPSEEK_API_KEY。


三、日常使用
------------

  双击 whalechan.cmd          → 交互式聊天（有立绘、状态栏、余额、表情包）
  whalechan.cmd --once "..."  → 干完一件事就退出，适合脚本/IDE 里挂

  在 IDE 里想让它像内置命令一样：把 U 盘这个目录加进 PATH，之后敲
  whalechan 就行。


四、为什么盘符变了也能跑
------------------------

  启动器里没有一处写死盘符，全靠 %~dp0 现算：

      set "ROOT=%~dp0"                  ← 本文件所在目录
      set "PATH=%ROOT%\node;%PATH%"
      set "DSH_HOME=%ROOT%\data"
      set "WHALE_MEMORY_DIR=%ROOT%\data\whale-chan"
      set "DSH_BIN=%ROOT%\app\...\dsh\lib\bin.js"

  今天插上是 E:，明天换台机器是 G:，都不用改。


五、几个要知道的
----------------

  · 首次在**新电脑**上跑，dsh 可能会在自己的 data\profiles\ 里
    初始化运行环境。请保证那台电脑**能上网**。

  · U 盘上放的是**明文的 API Key**。丢了 U 盘就等于别人能用你的额度。
    介意的话就别用 key.txt，改成每次在电脑上设环境变量。

  · **USB 3.0 才顺畅**（蓝色口）。USB 2.0 上第一次启动会慢十几秒，
    因为要从 U 盘读几百 MB 的 node_modules。

  · U 盘格式建议 **exFAT**。FAT32 单文件上限 4 GB（我们没这么大文件，
    但别的会撞）；NTFS 也行，只是插到部分设备上会只读。

  · 人设、记忆、好感度全在 data\whale-chan\ 里：
        形象卡.md   ← 人设 + 会话日志 + 好感度（主文件）
        记忆.md     ← 没挂形象卡时的备用记忆
        state.json  ← 会话 id（按目录各记一份）
    换台电脑想带着走，把这个目录一起拷过去就行。


六、出问题了
------------

  双击后窗口一闪就没了
      在终端里手动跑 whalechan.cmd，就能看到错误信息。

  提示「找不到 U 盘上的 node / dsh」
      目录没拷全。整个文件夹重新拷一遍。

  「智能体退出（code 1）」
      升级到 1.8.2 之后不会再有这个了。如果还出现，是把旧版目录拷过来的。

  余额 / 聊天报网络错
      鲸鱼娘自己是**不连网**的，联网的是她启动的 dsh 子进程。检查那台
      电脑能不能访问 api.deepseek.com。
